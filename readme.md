# 🔍 GitHub Profile Explorer

A modern GitHub Profile Viewer that allows users to search any GitHub username and instantly view their avatar, name, username, bio, followers, following, and public repositories.  
Built using Fetch API, Promises, clean UI transitions.

---

## 🌟 Features
- Search any GitHub user
- Fetches real-time GitHub profile data
- Smooth animated profile card
- Clean dark UI themed design
- Loading state + error handling

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (Fetch API, Promises)
