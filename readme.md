# 🔍 GitHub Profile Explorer

A polished and fast GitHub Profile Viewer that lets you search any GitHub username and instantly see their profile details — avatar, name, username, bio, followers, following, and top repositories.

Built with a clean dark UI, smooth stagger animations, and efficient API handling.

---

## 🚀 Features

### 🔎 **User Search**

* Fetch any GitHub user's public info in real-time
* Error handling for invalid usernames

### 🧑‍💻 **User Details Display**

* Avatar, name, username
* Bio
* Followers / Following count
* Public repo count

### ⭐ **Top Repositories**

* Fetches all repositories
* Sorts by star count (descending)
* Shows top 5 with:

  * Repo name
  * Stars
  * Primary language
  * Opens in new tab

### 🎞️ **Smooth UI Animations**

* Staggered fade‑in animation
* Reverse fade‑out on cancel
* Loader wave animation during fetch

### 🎨 **Modern UI**

* Full SCSS color system
* Dark gradient theme
* Glassy surfaces
* Clean, premium layout

---

## 🛠️ Tech Stack

### 1. Clone the repo

```bash

```

### 2. Open in VS Code

```bash

code .
```

### 3. Run the project

Open `index.html` in your browser.
